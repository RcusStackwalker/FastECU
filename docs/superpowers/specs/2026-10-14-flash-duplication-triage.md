# Remaining flash duplication triage

Open work from the 89-pair scan described in the
[investigation](2026-10-14-flash-duplication-investigation.md), grouped by
implementation boundary and evidence dependency. Original pair IDs are stable;
this is no longer a complete scan inventory. Completed extractions and decisions
to retain duplication or explicit geometry have been removed. Mixed dispositions
remain only for their open extraction or investigation scope.

The [implementation plan](../plans/2026-10-16-flash-duplication-remaining.md)
records the completed extraction and characterization series. The remaining rows
track bounded follow-ups and missing independent protocol evidence; they do not
authorize further implementation or establish hardware qualification.

**Extract** requires independent characterization before moving code.
**Investigate** requires an evidence-backed disposition before extraction or
behavior changes. In mixed rows, retain the surrounding orchestration and pursue
only the named bounded operation. Completed pure plan checks, Denso BEEF K-Line
operations and probe/stop retain decisions live in the
[current sharing contract](../../design-notes.md#share-only-proven-protocol-equivalence).

Coordinates are historical scanner hints, not extraction boundaries or current
line numbers. Inspect the named enclosing responsibility. Source links resolve
to whole files. Report baseline: jscpd 4.0.8, cpp+c-header, 10 lines/70 tokens;
external reference mapping remains incomplete.

## Evidence limits

RomRaider `src/main/java/com/romraider/io/protocol/ssm/iso9141/SSMProtocol.java`
can corroborate SSM framing, not flash retries, timing, or erase policy.
EcuFlash `ecuflash_flat_5630.bin` contains family/kernel strings, but corresponding
flash functions have not yet been mapped in `decomp_batch.txt`. A missing
implementation or an unmapped string is no verdict on protocol equivalence.

Preserve the [current sharing contract](../../design-notes.md#share-only-proven-protocol-equivalence)
and [qualification status](../../flash-qualification-matrix.md). Behavior changes
need independent evidence, a reproducing regression test, and a separate decision;
characterization tests alone establish only current behavior.
