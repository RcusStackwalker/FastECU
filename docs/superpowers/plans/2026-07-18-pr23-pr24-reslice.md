# Re-slice PR #23 and #24 into 6 Focused PRs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two large open PRs (#23 remove-qmake, #24 clang-tidy) with 6 small single-concern PRs across two independent tracks, each reviewable in one sitting.

**Architecture:** Pure git re-slicing — no source changes beyond what the two branches already contain. Each new PR is built by cherry-picking a subset of the original branches' commits onto `master`. The two split-commits (`808b8ec`, `7e2687a`) divide by whole file. There is no TDD here; the "test" for each task is that the relevant Bazel build/test/lint command stays green.

**Tech Stack:** git, GitHub CLI (`gh`), Bazel 9, prek (pre-commit).

## Global Constraints

- **Branch strategy: sequential off `master`.** Each PR targets `master` and is built/opened **only after its predecessor in the same track has merged**, so every cherry-pick lands on a `master` that already contains its predecessors — matching original authoring context and keeping cherry-picks clean. Do not create stacked branches.
- **The two tracks are independent** (Track 1 = qmake removal; Track 2 = clang-tidy). They may progress in parallel. Within a track, order is strict.
- **No qmake file is deleted before Task 3 (PR C).** Tasks 1–2 must remain revertible without touching qmake.
- **Do not** re-assert the `external/ → hardware/` rename in any PR description — it is not in the diff (stale body text from #23).
- Source commits live on `origin/remove-qmake-bazel` (Track 1) and `origin/markelov/actionable-clang-tidy` (Track 2). Run `git fetch origin` before starting.
- After the 6 PRs are open/merged, **close PR #23 and #24** with a comment pointing at the replacements.
- `docs/superpowers/` is gitignored in this repo; the spec and this plan are intentionally local-only. Do not try to commit them.

git commit -m "build: point clang-tidy targets at the public compile-commands target"
