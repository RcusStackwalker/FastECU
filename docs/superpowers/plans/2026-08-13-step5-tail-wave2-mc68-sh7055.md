# Step 5 Tail Wave 2 (MC68HC16Y5_02 / SH7055_02) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port `FlashEcuSubaruDensoMC68HC16Y5_02` and `FlashEcuSubaruDensoSH7055_02` from Qt legacy operations to portable `FlashPlan`/`IFlashExecutor` pairs, wire them through `FlashWorkflowFactory`, and delete the legacy classes + their dialogs.

**Architecture:** Each family gets a plan builder (`build_subaru_denso_<family>_plan`) and an `IFlashExecutor` under `src/backend/flash/ecu/`, following the `DensoSh705xEepromKlineExecutor`/`SubaruMitsuM32rKlineExecutor` precedent exactly: `IKlineFlashTransport`, `Result`/`Status` everywhere, cancellation checked around every I/O boundary, one local helper per shared wire shape. Both plans require a `KernelImage` (loaded via `IFileRepository`, not user-facing). Desktop wiring is two new `Route::Kind` rows in `flash_workflow.cpp`'s `kRoutes` table plus two `FlashWorkflow` subclasses — no per-family `QDialog` is written or kept; `FlashWorkflowFactory::tryCreate` is already checked before `mainwindow.cpp`'s legacy dispatch chain, so deleting the legacy `else if` branches and per-family dialog files is the whole "UI" side.

**Tech Stack:** C++23, Bazel `cc_library`/`fastecu_portable_gtest`, GoogleTest.

**Spec:** [docs/superpowers/specs/2026-08-13-step5-tail-wave2-mc68-sh7055-design.md](../specs/2026-08-13-step5-tail-wave2-mc68-sh7055-design.md)

## Global Constraints

- Every ported exchange's implementation comment cites the legacy file and line range it was transcribed from (umbrella fidelity rule).
- No new `ErrorKind` values (umbrella's fixed seven).
- `//src/backend/flash/ecu` targets stay Qt-free; register each new target in `PORTABLE_ROOTS` (`scripts/check-portable-closure.py`) in the same commit that adds it.
- `family_requires_kernel_v` defaults to `true` — do not add an override for either new plan struct; both families genuinely require a kernel.
- Legacy `.cpp`/`.h` pairs are the only source of truth for correct bytes; each is deleted in the same task that ports its last consumer, never left half-migrated.
- `scripts/check-legacy-flash-drain.py`'s `REMAINING` may only shrink; remove exactly one entry per family once its legacy operation file is deleted.
- Dead legacy members are not ported: MC68's `tester_id`/`target_id`/`CRC32`, SH7055's `CRC32`/`send_sid_27_request_seed`/`send_sid_27_send_seed_key` (verified unused by grep in the design phase — do not resurrect them for "symmetry").
- `sub_ecu_denso_mc68hc16y5_02_bdm` must never be claimed by the new MC68 routing entry (see Task 10) — it is a different, already-dispatched legacy family.

#include <format>
#include <utility>

#include "src/backend/definitions/kernelmemorymodels.h"
#include "src/backend/flash/flash_device_lookup.h"
#include "src/backend/flash/flash_validation.h"

namespace fastecu::flash

// mainwindow.cpp:1250-1258: sub_ecu_denso_mc68hc16y5_02(_ecutek)? and the
// reachable-but-quirky _02_tpu (see spec) all construct this class; _04/
// _04_ecutek are wired to it too (mainwindow.cpp:1255-1258) but
// protocols.cfg declares read=n/a|no, test_write=no, write=no for both --
// rejected outright, not merely un-writable.
Status validate_identity(std::string_view protocol, std::string_view mcu)
{
    using enum ErrorKind;
    if (protocol != "sub_ecu_denso_mc68hc16y5_02" &&
        protocol != "sub_ecu_denso_mc68hc16y5_02_ecutek" &&
        protocol != "sub_ecu_denso_mc68hc16y5_02_tpu" &&
        protocol != "sub_ecu_denso_mc68hc16y5_04" &&
        protocol != "sub_ecu_denso_mc68hc16y5_04_ecutek")
    {
        return fail(InvalidConfig, std::format("Unsupported MC68HC16Y5_02 protocol: {}", protocol));
    }
    if (protocol == "sub_ecu_denso_mc68hc16y5_04" || protocol == "sub_ecu_denso_mc68hc16y5_04_ecutek")
    {
        return fail(Unsupported,
                    "protocols.cfg declares no supported operation for MC68HC16Y5 revision 04");
    }
    if (find_flash_device_index(mcu) < 0)
    {
        return fail(InvalidConfig, std::format("Unknown MCU type: {}", mcu));
    }
    return {};
}

SubaruDensoMc68hc16y5_02Plan wire_params(std::string_view protocol)
{
    // flash_ecu_subaru_denso_mc68hc16y5_02_operation.cpp:126-137 (response
    // selection), 204-242 (baud/encryption/magic selection). Only "_ecutek"
    // is reachable via protocols.cfg (see spec's "_cobb" note); every other
    // accepted name takes the stock branch.
    if (protocol.ends_with("_ecutek"))
    {
        return {.connect_baud = 9600,
                .kernel_baud = 11700,
                .encryption_xor = 0x51,
                .kernel_magic = 0x3940,
                .bootloader_ok = {0x4C, 0x00, 0xB4}};
    }
    return {.connect_baud = 9600,
            .kernel_baud = 9600,
            .encryption_xor = 0x55,
            .kernel_magic = 0x3941,
            .bootloader_ok = {0x4D, 0x00, 0xB3}};
}

} // namespace

Status validate_subaru_denso_mc68hc16y5_02_plan(const FlashPlan& plan)
{
    using enum ErrorKind;
    if (auto valid = validate_identity(plan.target_id(), plan.mcu_name()); !valid.has_value())
    {
        return valid;
    }
    if (plan.family() != FlashFamily::SubaruDensoMc68hc16y5_02 || plan.transport() != TransportKind::Kline)
    {
        return fail(InvalidConfig, "plan is not for MC68HC16Y5_02");
    }
    if (!std::holds_alternative<SubaruDensoMc68hc16y5_02Plan>(plan.family_plan()))
    {
        return fail(InvalidConfig, "MC68HC16Y5_02 wire parameters are missing");
    }
    if (!plan.kernel().has_value())
    {
        return fail(InvalidConfig, "MC68HC16Y5_02 requires a kernel image");
    }
    const int index = find_flash_device_index(plan.mcu_name());
    if (index < 0)
    {
        return fail(InvalidConfig, "Unknown MCU type");
    }
    const std::uint32_t romsize = flashdevices[index].romsize;
    if (plan.operation() == FlashOperation::Write &&
        (!plan.image().has_value() || plan.image()->size() != romsize))
    {
        return fail(InvalidConfig, std::format("ROM file must be exactly 0x{:x} bytes", romsize));
    }
    return {};
}

Result<FlashPlan> build_subaru_denso_mc68hc16y5_02_plan(FlashOperation operation,
                                                         std::string_view protocol_name,
                                                         std::string_view mcu_type,
                                                         std::optional<bytes::Bytes> image,
                                                         KernelImage kernel)
{
    if (auto valid = validate_identity(protocol_name, mcu_type); !valid.has_value())
    {
        return std::unexpected(valid.error());
    }
    const int index = find_flash_device_index(mcu_type);
    const std::uint32_t romsize = flashdevices[index].romsize;
    if (operation == FlashOperation::Write && (!image.has_value() || image->size() != romsize))
    {
        return fail(ErrorKind::InvalidConfig,
                    std::format("ROM file must be exactly 0x{:x} bytes", romsize));
    }

    FlashPlanFields fields{
        .operation = operation,
        .family = FlashFamily::SubaruDensoMc68hc16y5_02,
        .transport = TransportKind::Kline,
        .target_id = std::string(protocol_name),
        .mcu_name = std::string(mcu_type),
        .transfer_region = MemoryRegion{flashdevices[index].fblocks[0].start, romsize},
        .erase_regions = {}, // per-block erase happens inside the write executor
                             // (blank-page-per-modified-block, legacy
                             // flash_block():950-992), not a fixed up-front set
        .image = operation == FlashOperation::Write ? std::move(image) : std::nullopt,
        .kernel = std::move(kernel),
        .family_plan = wire_params(protocol_name),
    };
    auto plan = validate_and_build(std::move(fields));
    if (!plan.has_value())
    {
        return std::unexpected(plan.error());
    }
    if (auto valid = validate_subaru_denso_mc68hc16y5_02_plan(*plan); !valid.has_value())
    {
        return std::unexpected(valid.error());
    }
    return plan;
}
} // namespace fastecu::flash

// src/backend/flash/ecu/subaru_denso_mc68hc16y5_02_executor.cpp
#include "src/backend/flash/ecu/subaru_denso_mc68hc16y5_02_executor.h"

#include "src/algorithms/checksum/checksum_primitives.h"

#include <utility>

constexpr std::uint16_t kStartComm = 0xBEEF;
constexpr std::uint8_t kOpId = 0x01;
constexpr std::uint8_t kOpUploadKernel = 0x53; // SUB_UPLOAD_KERNEL -- NOT header-framed

// Shared shape of every SUB_KERNEL_START_COMM-framed request in this file:
// [0xBE][0xEF][len+1 hi][len+1 lo][opcode][...payload][checksum8]. Used by
// this task's connect/upload, and by Tasks 5-6's read/write phases.
bytes::Bytes frame(std::uint8_t opcode, bytes::ByteView payload = {})
{
    bytes::Bytes out{static_cast<bytes::Byte>((kStartComm >> 8) & 0xFF),
                     static_cast<bytes::Byte>(kStartComm & 0xFF)};
    const std::uint16_t len_plus1 = static_cast<std::uint16_t>(payload.size() + 1);
    out.push_back(static_cast<bytes::Byte>((len_plus1 >> 8) & 0xFF));
    out.push_back(static_cast<bytes::Byte>(len_plus1 & 0xFF));
    out.push_back(opcode);
    out.insert(out.end(), payload.begin(), payload.end());
    out.push_back(fastecu::checksum::checksum8(out, false));
    return out;
}

bool response_ok(bytes::ByteView received, std::uint8_t expected_opcode_with_ack)
{
    return received.size() > 4 && received[0] == static_cast<bytes::Byte>((kStartComm >> 8) & 0xFF) &&
           received[1] == static_cast<bytes::Byte>(kStartComm & 0xFF) &&
           received[4] == expected_opcode_with_ack;
}

// write, then read with no inter-delay -- matches every
// write_serial_data_echo_check()+read_serial_data() pair in the legacy
// file. A timed-out response maps to ErrorKind::Timeout.
Result<bytes::Bytes> exchange(IKlineFlashTransport& transport, const ICancellationToken& cancellation,
                              bytes::ByteView request, int timeout_ms)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before write");
    }
    Result<std::size_t> written = transport.write(request);
    if (!written.has_value())
    {
        return std::unexpected(written.error());
    }
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled after write");
    }
    auto received = transport.read(timeout_ms, cancellation);
    if (!received.has_value())
    {
        return std::unexpected(received.error());
    }
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled after read");
    }
    if (!received->has_value())
    {
        return fail(ErrorKind::Timeout, "no response from ECU");
    }
    return std::move(**received);
}

// request_kernel_id(), lines 1139-1169: 200ms delay between write and read,
// short (2000ms) read timeout. An empty/short response is NOT an error --
// it is "kernel not (yet) alive", interpreted by callers.
Result<bytes::Bytes> request_kernel_id(IKlineFlashTransport& transport, IClock& clock,
                                       const ICancellationToken& cancellation)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before write");
    }
    Result<std::size_t> written = transport.write(frame(kOpId));
    if (!written.has_value())
    {
        return std::unexpected(written.error());
    }
    if (Status slept = clock.sleep(200, cancellation); !slept.has_value())
    {
        return std::unexpected(slept.error());
    }
    auto received = transport.read(2000, cancellation);
    if (!received.has_value())
    {
        return std::unexpected(received.error());
    }
    if (!received->has_value())
    {
        return bytes::Bytes{};
    }
    return std::move(**received);
}

bool looks_kernel_alive(bytes::ByteView received)
{
    return response_ok(received, static_cast<bytes::Byte>(kOpId | 0x40));
}

} // namespace

// connect_bootloader(), lines 100-180.
Status SubaruDensoMc68hc16y5_02Executor::connect_bootloader(
    IKlineFlashTransport& transport, IClock& clock, const ICancellationToken& cancellation,
    IEventSink& events, const SubaruDensoMc68hc16y5_02Plan& family_plan, bool& kernel_alive)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before connect");
    }
    // lines 111-119: pulse, then the 3-byte WRX02 init request at connect_baud.
    if (Status slept = clock.sleep(200, cancellation); !slept.has_value())
    {
        return std::unexpected(slept.error());
    }
    // Pulse itself is a transport-level LEC toggle with no portable
    // equivalent surfaced on IKlineFlashTransport yet; DesktopKlineFlashTransport
    // performs it as part of configure()/open() today for the M32R Kline
    // family (see subaru_mitsu_m32r_kline_executor.cpp's connect phase for
    // the precedent) -- this executor relies on the same open()-time pulse,
    // not a mid-session call.
    if (Status slept = clock.sleep(200, cancellation); !slept.has_value())
    {
        return std::unexpected(slept.error());
    }
    events.log(LogLevel::Info, "Connecting to Subaru 01-05 16-bit K-Line bootloader...");
    const bytes::Bytes init_request{0x4D, 0xFF, 0xB4};
    Result<bytes::Bytes> init_resp = exchange(transport, cancellation, init_request, 200);
    if (!init_resp.has_value())
    {
        return std::unexpected(init_resp.error());
    }
    if (init_resp->size() >= 3 &&
        std::equal(init_resp->begin(), init_resp->begin() + 3, family_plan.bootloader_ok.begin()))
    {
        events.log(LogLevel::Info, "Connected to bootloader");
        kernel_alive = false;
        return {};
    }
    events.log(LogLevel::Warning, "Bad response from bootloader, checking for a running kernel...");

    // lines 149-179: fall back to a kernel-alive probe at 62500 baud.
    if (Status baud = transport.setBaud(62500); !baud.has_value())
    {
        return std::unexpected(baud.error());
    }
    Result<bytes::Bytes> probe = request_kernel_id(transport, clock, cancellation);
    if (!probe.has_value())
    {
        return std::unexpected(probe.error());
    }
    if (probe->size() <= 4)
    {
        return fail(ErrorKind::BadResponse, "No valid response from ECU");
    }
    if (!looks_kernel_alive(*probe))
    {
        return fail(ErrorKind::BadResponse, "Wrong response from ECU");
    }
    kernel_alive = true;
    events.log(LogLevel::Info, "Kernel already running");
    return {};
}

// upload_kernel(), lines 182-318.
Status SubaruDensoMc68hc16y5_02Executor::upload_kernel(
    IKlineFlashTransport& transport, IClock& clock, const ICancellationToken& cancellation,
    IEventSink& events, const SubaruDensoMc68hc16y5_02Plan& family_plan, const KernelImage& kernel)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before kernel upload");
    }
    if (kernel.bytes.empty())
    {
        return fail(ErrorKind::InvalidConfig, "kernel image is empty");
    }
    if (Status baud = transport.setBaud(family_plan.kernel_baud); !baud.has_value())
    {
        return std::unexpected(baud.error());
    }

    // lines 220-250: pad to a 0x10 (16-byte) multiple, encrypt every byte
    // with xor+add, then patch the 2-byte magic word into encrypted[2..3].
    bytes::Bytes payload = kernel.bytes;
    while (payload.size() % 0x10 != 0)
    {
        payload.push_back(0x00);
    }
    for (auto& byte : payload)
    {
        byte = static_cast<bytes::Byte>((byte ^ family_plan.encryption_xor) + 0x10);
    }
    payload[2] = static_cast<bytes::Byte>((family_plan.kernel_magic >> 8) & 0xFF);
    payload[3] = static_cast<bytes::Byte>(family_plan.kernel_magic & 0xFF);

    // lines 256-269: raw (not SUB_KERNEL_START_COMM-framed) upload request:
    // [0x53][addr_hi][addr_mid][len_hi][len_mid][len_lo][payload][checksum8
    // dec0x100=true].
    const std::uint32_t addr = kernel.load_address;
    const std::uint32_t len = static_cast<std::uint32_t>(payload.size());
    bytes::Bytes request{kOpUploadKernel,
                         static_cast<bytes::Byte>((addr >> 16) & 0xFF),
                         static_cast<bytes::Byte>((addr >> 8) & 0xFF),
                         static_cast<bytes::Byte>((len >> 16) & 0xFF),
                         static_cast<bytes::Byte>((len >> 8) & 0xFF),
                         static_cast<bytes::Byte>(len & 0xFF)};
    request.insert(request.end(), payload.begin(), payload.end());
    request.push_back(fastecu::checksum::checksum8(request, true));

    events.log(LogLevel::Info, "Sending kernel...");
    Result<bytes::Bytes> upload_resp = exchange(transport, cancellation, request, 200);
    if (!upload_resp.has_value())
    {
        return std::unexpected(upload_resp.error());
    }
    if (!upload_resp->empty())
    {
        // line 276-281: ANY non-empty response is an upload error.
        return fail(ErrorKind::BadResponse, "Error on kernel upload");
    }
    events.log(LogLevel::Info, "Kernel uploaded successfully");

    // lines 289-317: 1500ms settle, switch to 62500, poll kernel ID.
    if (Status slept = clock.sleep(1500, cancellation); !slept.has_value())
    {
        return std::unexpected(slept.error());
    }
    if (Status baud = transport.setBaud(62500); !baud.has_value())
    {
        return std::unexpected(baud.error());
    }
    Result<bytes::Bytes> id = request_kernel_id(transport, clock, cancellation);
    if (!id.has_value())
    {
        return std::unexpected(id.error());
    }
    if (id->size() <= 4)
    {
        return fail(ErrorKind::BadResponse, "No valid response from ECU");
    }
    if (!looks_kernel_alive(*id))
    {
        return fail(ErrorKind::BadResponse, "Wrong response from ECU");
    }
    events.log(LogLevel::Info, "Kernel is alive");
    return {};
}

constexpr std::uint16_t kStartComm = 0xBEEF;
constexpr std::uint8_t kOpId = 0x01;

bytes::Bytes frame(std::uint8_t opcode, bytes::ByteView payload = {})
{
    bytes::Bytes out{static_cast<bytes::Byte>((kStartComm >> 8) & 0xFF),
                     static_cast<bytes::Byte>(kStartComm & 0xFF)};
    const std::uint16_t len_plus1 = static_cast<std::uint16_t>(payload.size() + 1);
    out.push_back(static_cast<bytes::Byte>((len_plus1 >> 8) & 0xFF));
    out.push_back(static_cast<bytes::Byte>(len_plus1 & 0xFF));
    out.push_back(opcode);
    out.insert(out.end(), payload.begin(), payload.end());
    out.push_back(fastecu::checksum::checksum8(out, false));
    return out;
}

bool response_ok(bytes::ByteView received, std::uint8_t expected_opcode_with_ack)
{
    return received.size() > 4 && received[0] == static_cast<bytes::Byte>((kStartComm >> 8) & 0xFF) &&
           received[1] == static_cast<bytes::Byte>(kStartComm & 0xFF) &&
           received[4] == expected_opcode_with_ack;
}

Result<bytes::Bytes> exchange(IKlineFlashTransport& transport, const ICancellationToken& cancellation,
                              bytes::ByteView request, int timeout_ms)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before write");
    }
    Result<std::size_t> written = transport.write(request);
    if (!written.has_value())
    {
        return std::unexpected(written.error());
    }
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled after write");
    }
    auto received = transport.read(timeout_ms, cancellation);
    if (!received.has_value())
    {
        return std::unexpected(received.error());
    }
    if (!received->has_value())
    {
        return fail(ErrorKind::Timeout, "no response from ECU");
    }
    return std::move(**received);
}

Result<bytes::Bytes> request_kernel_id(IKlineFlashTransport& transport, IClock& clock,
                                       const ICancellationToken& cancellation)
{
    if (cancellation.cancelled())
    {
        return fail(ErrorKind::Cancelled, "cancelled before write");
    }
    Result<std::size_t> written = transport.write(frame(kOpId));
    if (!written.has_value())
    {
        return std::unexpected(written.error());
    }
    if (Status slept = clock.sleep(200, cancellation); !slept.has_value())
    {
        return std::unexpected(slept.error());
    }
    auto received = transport.read(2000, cancellation);
    if (!received.has_value())
    {
        return std::unexpected(received.error());
    }
    if (!received->has_value())
    {
        return bytes::Bytes{};
    }
    return std::move(**received);
}

{
    return response_ok(received, static_cast<bytes::Byte>(kOpId | 0x40));
}

```cpp
class SubaruDensoMc68hc16y5_02Workflow final : public FlashWorkflow
{
  public:
    explicit SubaruDensoMc68hc16y5_02Workflow(FlashWorkflowRequest request)
        : request_(std::move(request))
    {
    }
    FlashWorkflowStep next() override
    {
        if (terminal_)
        {
            return completed(outcome_, std::move(bytes_));
        }
        if (!plan_)
        {
            QtFileRepository repository;
            Result<std::vector<std::uint8_t>> kernel_bytes =
                repository.read(request_.paths.kernel_files_directory + "ssmk_hc16.bin");
            if (!kernel_bytes.has_value())
            {
                return FlashFailureStep{kernel_bytes.error()};
            }
            plan_ = build_subaru_denso_mc68hc16y5_02_plan(
                request_.operation, request_.protocol, request_.mcu, request_.image,
                KernelImage{.id = request_.protocol + "-kernel",
                           .load_address = 0x20000,
                           .bytes = std::move(*kernel_bytes)});
        }
        if (!plan_->has_value())
        {
            return FlashFailureStep{plan_->error()};
        }
        if (!begun_)
        {
            return FlashPromptStep{FlashPromptKind::Begin, {}};
        }
        if (!attempted_)
        {
            attempted_ = true;
            return FlashAttempt{**plan_, std::make_unique<SubaruDensoMc68hc16y5_02Executor>(),
                                std::make_unique<DesktopKlineFlashTransport>(request_.serial),
                                std::make_unique<QtClock>()};
        }
        return completed(outcome_, std::move(bytes_));
    }
    void submit(FlashPromptResponse response) override
    {
        begun_ = true;
        if (response != FlashPromptResponse::Accept)
        {
            terminal_ = true;
            outcome_ = FlashWorkflowOutcome::Cancelled;
        }
    }
    void submit(FlashAttemptResult result) override
    {
        terminal_ = true;
        if (result.success)
        {
            outcome_ = FlashWorkflowOutcome::Succeeded;
            bytes_ = std::move(result.read_bytes);
        }
        else if (result.error_kind == ErrorKind::Cancelled)
        {
            outcome_ = FlashWorkflowOutcome::Cancelled;
        }
        else
        {
            outcome_ = FlashWorkflowOutcome::Failed;
        }
    }

  private:
    FlashWorkflowRequest request_;
    std::optional<Result<FlashPlan>> plan_;
    bool begun_ = false;
    bool attempted_ = false;
    bool terminal_ = false;
    FlashWorkflowOutcome outcome_ = FlashWorkflowOutcome::Failed;
    std::optional<bytes::Bytes> bytes_;
};
```
